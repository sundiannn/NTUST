## 重點摘要

- 同一個數位設計可以用**真值表（truth table）**、**邏輯式（logic expression）**、**閘級網表（gate netlist）**、**電晶體電路（transistor circuit）**四種方式表示。
- 循序電路分兩種：**Mealy 機**的輸出由**輸入與狀態**決定；**Moore 機**的輸出**只由狀態**決定。
- 正反器（flip-flop）在時脈**邊緣**動作，閂鎖器（latch）在時脈**準位**期間動作；資料在**建立時間（setup time）**與**保持時間（hold time）**的窗口內不可改變。
- 兩種設計方式：**全客製化（full custom）**＝「capture-and-simulate」；**以元件庫為基礎的合成（cell-based synthesis）**＝用 HDL「describe-and-synthesize」。
- **缺陷水準（defect level）**由**測試圖樣（test patterns）**的品質決定；**可測試性設計（Design for Testability, DFT）**就是為了產生更好的測試圖樣。

## 公式整理

| 前綴 | 中文 |

> 講義的歷史例子：1971 年 Intel 4004 為 4 位元微處理器，約 2300 個電晶體。

### 1.2 晶片設計與製造流程

構想（Idea）→ 架構設計（Architecture Design，畫方塊圖）→ 電路與佈局設計（Circuit & Layout Design）→ 佈局（Layout）→ IC 製造（晶圓上有數百顆晶粒 die）→ 切割與封裝（Sawing & Packaging）→ 測試（Testing）→ 良品交給客戶、不良品淘汰。

**封裝種類**：DIP（雙列直插）、PGA（針格陣列）、CCP（晶片載體）、QFP（四方扁平）、BGA（球格陣列）、MCM（多晶片模組）。

**台灣半導體產業鏈**：IC 設計 → IC 製造（晶圓代工、記憶體製造）→ 封裝 → 測試。

### 1.3 缺陷水準

$$
\text{Defect Level} = \frac{\#\ \text{bad chips}}{\#\ \text{total shipped chips}}
$$

| 符號 | 意義 | 單位 |
|---|---|---|
| Defect Level | 缺陷水準（可能的退貨率） | — |
| # bad chips | 出貨中的不良晶片數 | 顆 |
| # total shipped chips | 出貨晶片總數 | 顆 |

- 測試圖樣的品質決定缺陷水準。
- **DFT 流程**與設計流程並行，目的是產生更高品質的測試圖樣（提升可測試性），讓通過測試的都是好晶片。

### 1.4 製程演進與 IC 分類

| 年代 | 製程 | 階段 |
|---|---|---|
| 1990～1995 | 0.8 → 0.6 → 0.5 μm | 次微米（Submicron） |
| 2000～2006 | 0.35 → 0.25 → 0.18 μm | 深次微米（Deep Submicron） |
| 2010 之後 | 0.1 μm 以下 | 奈米（Nanometer） |

| 大類 | 細分 |
|---|---|
| 記憶體 IC | 揮發性：DRAM、SRAM；非揮發性：MASK ROM、EPROM、EEPROM、FLASH |
| 微元件 IC | MPU、MCU、微處理器週邊 IC、DSP |
| 邏輯 IC | 標準邏輯 IC；特殊應用 IC（ASIC）：PLD、閘陣列（Gate Array）、元件庫設計（CBIS）、全客戶設計 |
| 類比 IC | 線性 IC（功率 IC）；線性和數位混合 IC（LCD 驅動 IC、混合式 IC） |

### 1.5 邏輯準位

| 電壓範圍 | 判讀 |
|---|---|
| $V_{H(min)}$ ～ $V_{H(max)}$ | HIGH（二進位 1） |
| $V_{L(max)}$ ～ $V_{H(min)}$ | 不可接受的區間 |
| $V_{L(min)}$ ～ $V_{L(max)}$ | LOW（二進位 0） |

### 1.6 數位設計的四種表示法（講義例子）

$$
Z = A' \cdot B' \cdot (C + D)
$$

| 符號 | 意義 | 單位 |
|---|---|---|
| $A, B, C, D$ | 輸入 | — |
| $Z$ | 輸出 | — |
| $A'$ | $A$ 的補數（NOT） | — |

閘級網表：$A'$、$B'$ 各一個反相器，$T_2 = C + D$ 用 OR，$T_1 = B' \cdot T_2$，$Z = A' \cdot T_1$。

### 1.7 循序電路

**同步時脈循序電路**：組合電路＋正反器，正反器的輸出回授到組合電路的輸入，由時脈脈衝同步。

| 時脈響應 | 元件 | 動作時機 |
|---|---|---|
| 正準位（positive level） | 閂鎖器 | 時脈為 1 的整段期間 |
| 正緣（positive edge） | 正緣觸發正反器 | 時脈 0 → 1 瞬間 |
| 負緣（negative edge） | 負緣觸發正反器 | 時脈 1 → 0 瞬間 |

**建立時間與保持時間**：在每個時脈有效邊緣前（setup）與後（hold）各有一小段窗口，**資料在這段窗口內不可以改變**。

| 機型 | 輸出取決於 | 架構 |
|---|---|---|
| Mealy | 輸入＋狀態變數 | 組合網路同時產生輸出與次態，次態存入狀態暫存器 |
| Moore | 只有狀態變數 | 組合電路 → 狀態暫存器 → 另一個組合電路產生輸出 |

> 講義在 Mealy 機提出的問題：輸入是否與時脈同步？

**控制與資料路徑互動**：控制邏輯（control logic）接收外部輸入與資料路徑回傳的**狀態條件（status conditions）**，對資料路徑（datapath）下**命令（commands）**；資料路徑處理輸入資料並產生輸出資料。

### 1.8 設計方式

| 項目 | 全客製化設計流程 | 以元件庫為基礎的合成流程 |
|---|---|---|
| 建立電路 | 組合電晶體網表 | 用 HDL（Verilog、VHDL）描述 |
| 驗證 | SPICE 模擬 | 合成工具依元件庫（cell library）產生網表 |
| 口號 | capture-and-simulate | describe-and-synthesize |
| 佈局 | 大多手動 | 可用自動工具 |
| 常見用途 | 高效能微處理器、記憶體 | — |

### 1.9 HDL 與邏輯合成

**硬體描述語言（Hardware Description Language, HDL）**是用來描述硬體邏輯電路的高階語言，能夠：

- 描述電路的連接（結構）
- 描述電路的功能（行為）
- 在不同抽象層次建模
- 描述時序資訊與時序限制
- 表達**同時性（concurrency）**

**為什麼用 HDL**：可重複使用（與實作無關的設計、testbench）、多種工具支援、可延後決定實作方式、及早找到錯誤、設計輸入快、容易管理。

**邏輯合成（logic synthesis）**：輸入布林式或 RTL 程式碼，產生能執行指定功能的邏輯閘網路；過程會對應到可用的閘，並針對延遲、面積、可測性、功耗等重新調整結構。合成是**受限制條件驅動（constraints driven）**的問題，最主要是**面積與延遲**之間的取捨。

### 1.10 FPGA 架構

- FPGA 由 N × N 的**可程式邏輯區塊（Programmable Logic Block, PLB）**陣列、**可程式 I/O 區塊**，以及**可程式連線網路（programmable interconnect）**組成。
- **組態記憶體（configuration memory）**中的位元決定每個邏輯區塊的功能與連線方式。
- **可程式連線點（CIP）**有三種：交叉點（cross-point）、斷點（break-point）、多工器（MUX）型，都由組態記憶體位元控制。
- Xilinx XC4000 的 **CLB（Configurable Logic Block）**：兩個 4 輸入邏輯函數產生器（F1–F4、G1–G4）、一個組合 F′、G′、H1 的函數產生器 H′，以及兩個 D 正反器（輸出 XQ、YQ）。

### 1.11 PLD 設計流程

| 步驟 | 內容 |
|---|---|
| 1. 設計規格（Design Specification） | — |
| 2. 設計輸入／RTL 撰寫 | 行為或結構描述 |
| 3. RTL 模擬 | 功能模擬，驗證邏輯與資料流（**不含時序延遲**） |
| 4. 合成（Synthesis） | 轉成目標元件的基本單元，並在面積、效能限制下最佳化 |
| 5. 佈置與繞線（Place & Route） | 把基本單元放到元件的實際位置，指定繞線資源 |
| 6. 時序分析（Timing Analysis） | 靜態時序分析（STA），確認效能規格 |
| 7. 閘級模擬（Gate Level Simulation） | 時序模擬，確認在目標技術上能正常運作 |
| 8. 電路板模擬與測試 | 模擬板子設計，燒錄元件並在板上測試除錯 |

### 1.12 設計品質

- **可測試性**：產生好的測試圖樣、有可靠的全速測試治具、設計可測試的晶片。
- **良率與可製造性**：功能良率（functional yield）、參數良率（parametric yield）。
- **可靠度（reliability）**、**技術可更新性（technology updateability）**。

## 解題技巧

### 題型一：判斷 Mealy 或 Moore

1. 看輸出是從哪裡產生的。
2. 輸出的組合邏輯**有接輸入** → Mealy。
3. 輸出只從**狀態暫存器**經過組合邏輯產生 → Moore。

### 題型二：由邏輯式畫閘級網表或寫真值表

1. 從括號最內層開始，每一個運算對應一個閘（例：$C + D$ 用 OR）。
2. 補數項先接反相器。
3. 依序把中間結果（$T_2$、$T_1$）接到下一級，最後得到輸出。
4. 寫真值表時，把每組輸入代入邏輯式計算。

### 題型三：PLD／FPGA 設計流程排序

1. 規格 → RTL 撰寫 → RTL（功能）模擬 → 合成 → 佈置與繞線 → 時序分析 → 閘級（時序）模擬 → 板上測試。
2. 記法：**功能模擬在合成之前、時序模擬在佈置繞線之後**。

## 常見陷阱

- 閂鎖器是**準位**觸發，正反器是**邊緣**觸發，不要混用。
- RTL 模擬沒有時序延遲，只能驗證功能；時序要靠 STA 與閘級模擬。
- 缺陷水準的分母是**出貨**晶片總數，不是生產總數。
