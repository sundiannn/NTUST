# Ch.1 通訊系統導論

> 依據：老師講義 Chapter 1 Introduction（1.1–1.5）｜更新：2026-11-15

## 重點摘要

- 任何通訊系統都由三個功能區塊組成：**發射機（transmitter）**、**傳輸媒介／通道（channel）**、**接收機（receiver）**；訊號在通道中一定會因雜訊、干擾、衰減與失真而劣化。
- 通道分成**有線媒介（wired）**（雙絞線、同軸電纜、光纖，點對點）與**無線媒介（wireless）**（無線電、紅外線，廣播式共用）；有線衰減隨距離**線性**增加（dB），無線衰減隨距離**對數**增加。
- 類比通訊靠**調變（modulation）**把訊息放到高頻載波上；數位通訊則依序經過**訊源編碼 → 通道編碼 → 數位調變**，接收端反向處理。
- 數位傳輸最大的優勢是**再生中繼器（regenerative repeater）**：只要判斷每個位元是 0 或 1，就能把訊號幾乎完美重建，雜訊不會像類比放大器那樣一路累積。
- 1948 年的「雙重大爆炸（double big bang）」：電晶體發明＋Shannon 發表〈A Mathematical Theory of Communication〉，奠定數位時代；Shannon 證明每個通道都有**通道容量（channel capacity）**。

## 公式整理

### 1.2 有線媒介的衰減

$$
\text{Attenuation}_{\text{wired}} = \alpha d \ \text{dB}
$$

| 符號 | 意義 | 單位 |
|---|---|---|
| $\alpha$ | 衰減常數（attenuation），距離用 km 時單位為 dB/km | dB/km |
| $d$ | 傳輸距離 | km |

> $\alpha$ 對大多數媒介都**和頻率有關**（頻率越高衰減越大），唯一例外是單模光纖。因為高頻成分被衰減得比較多，通道輸出會是輸入的**失真**版本。

### 1.2.3 無線媒介的路徑損耗

$$
\text{Path loss}_{\text{wireless}} = \alpha n \log_{10} d \ \text{dB}
$$

| 符號 | 意義 | 單位 |
|---|---|---|
| $n$ | 路徑損耗指數（path loss exponent），實測約 2～4 | — |
| $d$ | 傳輸距離（Fig. 1.12 實測圖以 km 為橫軸） | — |

> 無線訊號的衰減正比於 $d^n$，換成 dB 就變成 $\log d$ 的關係，所以無線訊號隨距離衰減得比有線慢得多。

### 1.2 各種傳輸媒介的重要數據

| 媒介 | 重點數據 |
|---|---|
| 雙絞線（twisted wire pair, TWP） | AWG 號數越小 → 線徑越粗 → 衰減越小；電信常用 22、24、26 AWG；Cat 5 支援 10/100 Mb/s 乙太網路；可用頻寬約數 MHz |
| 同軸電纜（coaxial cable） | 抗干擾與串音（crosstalk）優於雙絞線；可用頻寬達數百 MHz；RG-6 在 100 MHz 衰減 22.6 dB/km |
| 光纖（optical fiber） | 單模光纖在 1.55 μm 衰減約 0.25 dB/km，且與訊號頻率無關；1.25～1.625 μm 潛在頻寬可達 50 THz |
| 無線電（RF） | 頻譜範圍 3 kHz～300 GHz，由 ITU 全球分配 |

### 1.2.2 光纖的種類

| 類型 | 纖芯直徑 | 特點 |
|---|---|---|
| 步階折射率多模（step-index multimode） | 50～200 μm | 數值孔徑（NA）大、耦合光多，但脈波展寬（pulse spreading）嚴重；NA 常取 0.2～0.3 |
| 漸變折射率多模（graded-index multimode） | 約 50 μm（披覆 125 μm） | 纖芯折射率由中心向外呈拋物線遞減，補償不同路徑的時間差，脈波展寬較小 |
| 單模（single mode） | 8～10 μm（披覆 125 μm） | 只傳一條軸向光，沒有多模展寬；頻寬受光源不同波長速度不同所限；用於長距離、Gb/s 級網路 |

> 光在纖芯內靠**全反射（total internal reflection）**前進：入射角 ≥ 臨界角時，光完全反射回纖芯（纖芯折射率 $n_1$ > 披覆折射率 $n_2$）。

### 1.2.3 常見頻段（節錄自 Table 1.1）

| 頻段 | 範圍 | 代表應用 |
|---|---|---|
| VLF | 3–30 kHz | 無線電導航、潛艇通訊 |
| LF | 30–300 kHz | 海事通訊、導航 |
| MF | 300–3000 kHz | AM 廣播（530–1700 kHz） |
| HF | 3–30 MHz | 短波廣播 |
| VHF | 30–300 MHz | FM 廣播（88–108 MHz）、TV 2–13 台 |
| UHF | 300–3000 MHz | 行動電話、GPS（1227.6、1575.4 MHz）、Wi-Fi（2400–2483.5 MHz） |
| SHF | 3–30 GHz | 衛星通訊 |

> 衛星頻段寫成 4/6、11/14、20/30 GHz 時，**前面是下行（downlink）**、後面是上行（uplink）。行動通訊用 800/900 與 1800/1900 MHz；Wi-Fi 用 2.4 與 5 GHz。

## 解題技巧

### 題型一：畫出／說明系統方塊圖

1. **一般通訊系統**：訊息 →（輸入轉換器）→ 發射機 → 通道（加入雜訊）→ 接收機 → 輸出訊息。
2. **類比系統**（Fig. 1.13）：類比訊源 → 調變器 → 發射機輸出處理（濾波、頻率轉換、放大）→ 通道 → 接收機輸入處理（低雜訊放大、調諧選台、濾波）→ 解調器 → 目的地。
3. **數位系統**（Fig. 1.14）：訊源（類比的話先經 A/D）→ **訊源編碼器** → **通道編碼器** → **數位調變器** → 通道 → 數位解調器 → 通道解碼器 → 訊源解碼器 →（D/A）→ 目的地。加密／解密為選用。
4. 區分兩種編碼的目的：
   - **訊源編碼（source coding）／壓縮**：**移除**冗餘，讓表示更有效率（例：英文字母 E 出現機率 10.73%、B 只有 1.18%）。
   - **通道編碼（channel coding）**：**刻意加入**受控的冗餘，讓接收端能偵錯、更正。

### 題型二：比較類比與數位傳輸

1. **類比中繼（analog repeater）**：例如 CATV 每約 2000 英尺放一台放大器，放大訊號並等化高頻衰減，但**雜訊也一起被放大**，每一級還再加入新雜訊 → 雜訊累積，限制系統長度。
2. **數位再生中繼器**（Fig. 1.17）：前置放大／等化 → 時脈回復（timing recovery）→ 在每個位元**中點取樣**、和**門檻值（threshold）**比較 → 重新產生乾淨脈波。只有當雜訊大到讓取樣值越過門檻才會出錯。
3. 數位傳輸的其他優點（作答時列點）：
   - 一個網路承載所有服務（語音、影像、資料轉成位元後一視同仁）
   - 所需接收功率低好幾個數量級 → 涵蓋範圍大、電池小
   - 容易做多工、錯誤控制編碼、壓縮
   - 加密容易、安全
   - 享受摩爾定律（Moore's law，電晶體數約每兩年加倍）帶來的成本下降

### 題型三：有線 vs. 無線媒介比較

1. 有線：訊號能量被導引在固體媒介中，**點對點**連線；衰減 $\alpha d$（dB）隨距離線性增加。
2. 無線：以非導引電磁波傳播，**廣播式**共用媒介 → 同時存取會互相干擾；衰減 $\propto \log d$。
3. 無線特有的通道劣化：
   - **雨衰**：降雨使衰減增加
   - **遮蔽衰落（shadow fading）**：路徑上障礙物造成的衰減變化
   - **多路徑衰落（multipath fading）**：多個路徑的訊號副本疊加；若相差 180° 會完全抵消
   - 其他使用者的干擾

## 常見陷阱

- 「有線衰減與頻率無關」是錯的：只有**單模光纖**的衰減和訊號頻率無關，雙絞線、同軸電纜都是頻率越高衰減越大。
- AWG 號數和線徑是**反向**關係：號數越小，線越粗、衰減越小。
- 衛星頻段 4/6 GHz 中，**4 GHz 是下行**、6 GHz 是上行，不要記反。
- 訊源編碼是「去除冗餘」，通道編碼是「加入冗餘」，兩者方向相反。
- 在 Shannon 之前，工程師以為要降低錯誤率就必須降低傳輸速率；Shannon 證明只要速率不超過通道容量，就能用適當編碼達到幾乎無錯誤的傳輸。
- 數位再生中繼器不需要完整恢復原波形，只需判斷每個位元區間「有沒有脈波」。
