# 課程筆記與考古題庫

依「系所 → 類別 → 課程」整理的學習網站，每門課提供：

- **課程筆記整理**：各章講義的 AI 重點整理
- **歷屆試題**：期中考、期末考的 AI 解析

## 特色

- **規則與資料分離**：網站畫面全部由 JSON 產生。新增內容只要放一個 Markdown 檔、在 JSON 加一筆資料，不需要改程式。
- **AI 可接手維護**：專案規則寫在 [`AGENTS.md`](AGENTS.md)，AI 讀完就能依同一套模板與流程，繼續新增講義整理、試題解析、課程或系所。
- 深色工程風介面，支援 LaTeX 公式（KaTeX）與 Verilog 程式碼高亮。

## 本機預覽

```bash
python -m http.server 8000
# 開啟 http://localhost:8000
```

## 著作權說明

本站僅公開 AI 整理後的重點與解析，**不提供**老師的原始講義與考卷。原始素材只放在本機的 `_sources/` 資料夾，已列入 `.gitignore`。之後預計加入限國立臺灣科技大學學生使用的登入系統，屆時才會開放原始檔案。
